# AGENTS.md — Global Workspace Skill Guide

## Quality Standards

Always aim for **professional-grade, production-ready output**. This means:

- **Websites**: pixel-perfect responsive design, accessible, fast-loading, with polished typography and spacing. Use `react-tailwind`, `frontend-ui-engineering`, `ui-designer`, and `website-ui-ux-engineer` in combination. Audit with `accessibility-review` and `web-perf` before shipping.
- **Reports**: well-structured with executive summary, clear headings, data-backed insights, professional formatting. Chain `data-analysis` → `data-storytelling` (narrative framework) → `visualizing-data` (optimal charts) → `pdf-report-generation`. For academic publication quality, add `scientific-figure-making`.
- **Dashboards**: interactive, filterable, with KPI cards, charts, and clean data tables. Start with `build-dashboard` (Anthropic official, 5.8K installs) or use `visualizing-data` + `d3-visualization` for custom interactive viz. Polish with `infographic` for client-facing KPI snapshots.
- **Visualizations**: publication-quality charts with proper labels, colors, and legends. Use `visualizing-data` for chart selection (24+ types, WCAG-compliant), `scientific-figure-making` for academic figures, `d3-visualization` for custom interactive viz, and `infographic` for template-based client deliverables.
- **Financial work**: rigorous, formula-auditable, benchmark-aware. Use `financial-plan`, `creating-financial-models`, `longbridge-quant`. Add `business-analyst` for KPI framework design and market sizing.
- **Presentations**: polished slides with consistent branding. Use `presentation-generation` or `slidev`.
- **Research & Consulting**: synthesize findings into actionable insights. Chain `research-synthesis` (theme extraction) → `data-storytelling` (narrative) → `infographic` or `scientific-figure-making` (visual evidence) → `pdf-report-generation` (client deliverable).
- **Code Quality**: every change reviewed before merge. Use `code-review-and-quality` for five-axis review (correctness, readability, architecture, security, performance). Use `accessibility-review` for WCAG 2.1 AA compliance.

## Workflow Patterns — Chain Skills for Professional Results

### Executive Report Pipeline
```
data-analysis (analyze data) → visualizing-data (choose optimal charts)
    → data-storytelling (narrative framework) → pdf-report-generation (polished PDF)
```

### Professional Dashboard Pipeline
```
data-analysis (understand data) → build-dashboard (interactive HTML) or d3-visualization (custom viz)
    → frontend-ui-engineering (production polish) → accessibility-review (WCAG audit)
    → web-perf (performance check) → render-static-sites (deploy)
```

### Financial Analysis Pipeline
```
finance-manager (process transactions) → financial-plan (projections)
    → business-analyst (KPI framework + market sizing) → pdf-report-generation (client-ready report)
```

### Research Paper Pipeline
```
scraping-skills (gather data) → academic-research (methodology)
    → data-science (analysis) → scientific-figure-making (publication figures)
    → technical-article-writer (write paper)
```

### Website Development Pipeline
```
design-system (audit tokens) → ui-designer (design system) → react-tailwind + frontend-ui-engineering (build components)
    → website-ui-ux-engineer (responsive polish) → accessibility-review (WCAG AA audit)
    → web-perf (performance audit) → render-static-sites (deploy)
```

### Consulting Deliverable Pipeline
```
business-analyst (KPI framework + market analysis) → data-analysis (crunch numbers)
    → visualizing-data (optimal charts) → infographic (client-facing visuals)
    → data-storytelling (executive narrative) → pdf-report-generation (polished deliverable)
```

### Research Synthesis Pipeline
```
research-synthesis (theme extraction from interviews/surveys)
    → data-storytelling (build narrative) → infographic (visual summary)
    → pdf-report-generation (stakeholder report)
```

## Model & Effort Guidance

For professional-grade output on complex tasks, the agent should:
- Use **higher effort** (`subagent_effort = "high"` or `"max"`) for: `build-dashboard`, `d3-visualization`, `financial-plan`, `creating-financial-models`, `pdf-report-generation`, `academic-research`, `scientific-figure-making`, `business-analyst`
- Use **deepseek-pro** for subagent work on: design, finance, research, and data storytelling skills
- Use **deepseek-flash** for simpler skills: `docs-writing`, `xlsx`, `scraping-skills`, `infographic`
- Always use `frontend-ui-engineering` (not bare `react-tailwind`) when building production UI — it ensures the output avoids the "AI aesthetic" and meets accessibility standards
- Pair `visualizing-data` with any charting task to select the right visualization before coding

## General Principles

1. **Always invoke relevant skills** — don't try to do from scratch what a skill already handles. The catalog now spans 50+ skills across 11 categories. Scan it before starting any work.
2. **Chain skills** — professional output rarely comes from a single skill. Think in pipelines. The guide above lists 7 proven patterns; compose new ones as needed.
3. **Avoid the AI aesthetic** — use `frontend-ui-engineering` for UI (not bare `react-tailwind`), `visualizing-data` for chart selection (not guesswork), `data-storytelling` for narratives (not data dumps).
4. **Verify outputs** — run generated code, check PDFs render correctly, validate data before presenting. Use `code-review-and-quality` before merging any change.
5. **Audit before shipping** — run `accessibility-review` for WCAG 2.1 AA compliance and `web-perf` for Core Web Vitals on every web project.
6. **Ask clarifying questions** before building — scope, audience, format, brand guidelines.
7. **Prefer Anthropic-official skills** (build-dashboard, financial-plan, creating-financial-models) for mission-critical work — they're the most battle-tested.

### Usage Notes
- `folium` fills the GIS/mapping gap — perfect for economic development regional analysis, investment heatmaps, and diffusion visualizations
- `statsmodels` provides rigorous statistical output (p-values, confidence intervals, model diagnostics) for market research reports
- `streamlit` turns any Python analysis into a shareable interactive web app in minutes — ideal for client prototypes
- All three integrate naturally with already-installed `pandas`, `numpy`, `matplotlib`, and `plotly`
- For publication-quality static maps, use `folium` for exploration then `scientific-figure-making` for final figures
